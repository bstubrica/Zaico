## 🗄️ Esquema de Base de Datos PostgreSQL

> **Fuente de verdad:** el esquema operativo es el de `database.sql` (base de datos `Zaico`), extendido con las tablas de la Fase 2.
> Las tablas `USUARIOS`, `ROLES` y `PERMISOS` de `database.sql` quedan **obsoletas**: la autenticación la gestiona Laravel (tablas `users`, `sessions`, `password_reset_tokens` del esquema por defecto).
> `PERSONAL` se conserva como directorio de las personas a las que se les asignan equipos.
> Las migraciones de Laravel **replican estos nombres exactos** de tablas y columnas (en mayúsculas/con guiones bajos) para mantener compatibilidad con `database.sql`, los reportes existentes y la conexión directa de Power BI.

### Tablas de Autenticación (Laravel)
```sql
-- Gestionadas por Laravel/Breeze (migraciones de vendor + 0001_01_01_000000_create_users_table)

sessions             -- id (PK string), user_id, ip_address, user_agent, payload, last_activity
password_reset_tokens
```

    id                       INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    Nombre_de_activo         VARCHAR(150) NOT NULL,

    Serial                   VARCHAR(100) UNIQUE,

### ✅ Tarea 0.2: Crear Modelos de Dominio (Eloquent)

**Descripción:** Implementar los modelos Eloquent que representan las entidades del dominio. Se conservan los **nombres exactos** de tablas y columnas de `database.sql` (se declaran con `$table`, `$fillable` y `$casts`).

**Instrucciones para el Agente de IA:**

1. **Crear `app/Models/Activo.php`:**
   ```php
   <?php

   namespace App\Models;

   use Illuminate\Database\Eloquent\Model;
   use Illuminate\Database\Eloquent\Relations\BelongsTo;
   use Illuminate\Database\Eloquent\Relations\HasMany;
   use Illuminate\Database\Eloquent\Relations\HasOne;

   class Activo extends Model
   {
       protected $table = 'ACTIVOS';
       protected $primaryKey = 'id';
       public $timestamps = false; // usamos Creado_el / Actualizado_el

       protected $fillable = [
           'Nombre_de_activo', 'Ubicacion', 'Ubicacion_Predeterminada', 'Serial',
           'Fabricante', 'Categoria', 'Modelo', 'Observaciones', 'Etiqueta_activo',
           'Estado', 'Direccion_MAC', 'Imagen_Activo', 'fk_estado',
       ];

       protected $casts = [
           'Creado_el'       => 'datetime',
           'Actualizado_el'  => 'datetime',
       ];

       protected static function booted(): void
       {
           static::creating(fn (self $a) => $a->Creado_el = now());
           static::updating(fn (self $a) => $a->Actualizado_el = now());
       }

       public function estadoCatalogo(): BelongsTo
       {
           return $this->belongsTo(EstadoActivo::class, 'fk_estado', 'id');
       }

       public function asignaciones(): HasMany
       {
           return $this->hasMany(Asignacion::class, 'fk_Activo', 'id');
       }

       public function asignacionActiva(): HasOne
       {
           return $this->hasOne(Asignacion::class, 'fk_Activo', 'id')
               ->where('Estado', 'Activa');
       }

       public function personalAsignado(): BelongsTo
       {
           return $this->belongsTo(Personal::class, 'id')
               ->through('asignacionActiva'); // o resolver en el servicio
       }

       public function mantenimientos(): HasMany
       {
           return $this->hasMany(Mantenimiento::class, 'fk_activo', 'id');
       }

       public function compra(): HasOne
       {
           return $this->hasOne(Compra::class, 'fk_activo', 'id');
       }

       public function eventos(): HasMany
       {
           return $this->hasMany(HistorialEvento::class, 'fk_activo', 'id');
       }

       public function getAsignadoAAttribute(): ?string
       {
           $a = $this->asignacionActiva;
           return $a?->personal ? trim($a->personal->Nombre.' '.$a->personal->Apellido) : null;
       }
   }
   ```

3. **Detalles por tabla (resumen):**
   - `ESTADOS_ACTIVO`: `id`, `Nombre` unique(60), `Grupo`(30), `Deployed` bool default false, `Deployable` bool default false, `Estado` smallInteger default 1. Sin timestamps.
   - `PERSONAL`: `id`, `Nombre`(100), `Apellido`(100), `Nombre_usuario`(50) unique, `Cargo`(100), `Observaciones` text, `Estado`(20) default `'Activo'`. Sin timestamps.
   - `ASIGNACIONES`: `id`, FKs `fk_Activo`→ACTIVOS (restrictOnDelete), `fk_Personal`→PERSONAL (restrictOnDelete), `fk_usuario`→users (cascadeOnDelete), `Fecha_asignacion` date, `Fecha_devolucion` date nullable, `Observaciones` text, `Estado`(20) default `'Activa'`. Índices en `fk_Activo`, `fk_Personal`.
   - `COMPRAS`: `id`, `fk_activo` unique → ACTIVOS cascadeOnDelete, campos de compra, `Costo_compra` decimal(12,2).
   - `MANTENIMIENTOS`: `id`, `fk_activo` → ACTIVOS cascadeOnDelete, `Tipo`(30), `Descripcion` text, `Fecha_mantenimiento` date, `fk_usuario` → users, `Creado_el` timestampTz. Índices en `fk_activo`, `Fecha_mantenimiento`.
   - `EVIDENCIAS_MANTENIMIENTO`: `id`, `fk_mantenimiento` → MANTENIMIENTOS cascadeOnDelete, `Ruta_archivo`(300), `Nombre_original`(255), `Tipo_mime`(100), `Tamano_bytes` bigInteger, `Subido_el` timestampTz.
   - `HISTORIAL_EVENTOS`: `id` bigIncrements, `fk_activo` → ACTIVOS cascadeOnDelete, `Tipo_evento`(40), `Descripcion` text, `Valor_anterior`/`Valor_nuevo` text, `fk_usuario` nullable → users, `Fecha` timestampTz default now. Índices en `fk_activo`, `Fecha`.
   - `IMPORTACIONES_LOG` + `IMPORTACIONES_DETALLE`: como el DDL de la sección de esquema (`Datos_previos` como `jsonb` via `$table->jsonb()`).
   - `add_role_to_users_table`: `$table->string('role', 30)->default('SoporteTecnico')` tras `users`.

> **Nota:** si el esquema se creó desde `database.sql` (que usa triggers `fn_touch_actualizado_el` para `Actualizado_el`), ambas capas se refuerzan sin conflicto: Eloquent mantiene `Actualizado_el` y el trigger de PostgreSQL es la red de seguridad.

**Criterios de Aceptación:**
- ✅ `php artisan migrate` crea todas las tablas en PostgreSQL sin errores

### ✅ Tarea 0.5: Implementar Servicios de Negocio

**Descripción:** Crear la capa `app/Services` con la lógica de negocio (las reglas no van en controladores ni en vistas). Se inyectan por constructor (el contenedor de Laravel los resuelve automáticamente).

**Instrucciones para el Agente de IA:**

1. **Crear `app/Services/ActivoService.php`:**
   ```php
   <?php

   namespace App\Services;

   use App\Models\{Activo, Asignacion, EstadoActivo, HistorialEvento, Personal};
   use Illuminate\Contracts\Pagination\LengthAwarePaginator;
   use Illuminate\Support\Facades\DB;
   use RuntimeException;

   class ActivoService
   {
       public function listar(array $filtros): LengthAwarePaginator
       {
           return Activo::query()
               ->with(['estadoCatalogo', 'asignacionActiva.personal'])
               ->when($filtros['termino'] ?? null, function ($q, $t) {
                   $q->where(fn ($w) => $w
                       ->where('Nombre_de_activo', 'ilike', "%{$t}%")
                       ->orWhere('Serial', 'ilike', "%{$t}%")
                       ->orWhere('Etiqueta_activo', 'ilike', "%{$t}%")
                       ->orWhere('Modelo', 'ilike', "%{$t}%"));
               })
               ->when($filtros['categoria'] ?? null,
                   fn ($q, $c) => $q->where('Categoria', $c))
               ->when($filtros['estado'] ?? null, function ($q, $e) {
                   $q->whereHas('estadoCatalogo', fn ($w) =>
                       $w->where('Nombre', $e)->orWhere('Grupo', $e));
               })
               ->when($filtros['ubicacion'] ?? null,
                   fn ($q, $u) => $q->where('Ubicacion', 'ilike', "%{$u}%"))
               ->when($filtros['asignado_a'] ?? null, function ($q, $a) {
                   $q->whereHas('asignacionActiva.personal', fn ($w) =>
                       $w->whereRaw("trim(Nombre || ' ' || Apellido) ilike ?", ["%{$a}%"]));
               })
               ->orderBy('Nombre_de_activo')
               ->paginate($filtros['tamano'] ?? 50)
               ->withQueryString();
       }

       public function crear(array $datos, int $usuarioId): Activo
       {
           return DB::transaction(function () use ($datos, $usuarioId) {
               $activo = Activo::create($datos);
               $this->auditar($activo->id, 'Creacion', "Activo registrado: {$activo->Nombre_de_activo}", usuarioId: $usuarioId);
               return $activo->load('estadoCatalogo');
           });
       }

       public function cambiarEstado(Activo $activo, int $fkEstado, string $motivo, int $usuarioId): Activo
       {
           $estadoNuevo = EstadoActivo::findOrFail($fkEstado);
           $anterior = $activo->estadoCatalogo?->Nombre;

           return DB::transaction(function () use ($activo, $estadoNuevo, $motivo, $usuarioId, $anterior) {
               $activo->update(['Estado' => $estadoNuevo->Grupo, 'fk_estado' => $estadoNuevo->id]);
               $this->auditar($activo->id, 'CambioEstado', $motivo, $anterior, $estadoNuevo->Nombre, $usuarioId);
               return $activo->fresh('estadoCatalogo');
           });
       }

       public function asignar(Activo $activo, array $datos, int $usuarioId): Activo
       {
           if ($activo->asignacionActiva()->exists()) {
               throw new RuntimeException('El activo ya tiene una asignación activa. Devuélvalo primero.');
           }
           if ($activo->estadoCatalogo?->Grupo === 'Desincorporado') {
               throw new RuntimeException('No se puede asignar un activo desincorporado.');
           }
           $personal = Personal::findOrFail($datos['fk_Personal']);

           return DB::transaction(function () use ($activo, $datos, $usuarioId, $personal) {
               Asignacion::create([
                   'fk_Activo'         => $activo->id,
                   'fk_Personal'       => $personal->id,
                   'fk_usuario'        => $usuarioId,
                   'Fecha_asignacion'  => $datos['Fecha_asignacion'],
                   'Observaciones'     => $datos['Observaciones'] ?? null,
                   'Estado'            => 'Activa',
               ]);

               $estadoAsignado = EstadoActivo::where('Nombre', 'like', 'Asignado%')->first();
               if ($estadoAsignado) {
                   $activo->update(['Estado' => $estadoAsignado->Grupo, 'fk_estado' => $estadoAsignado->id]);
               }

               $this->auditar($activo->id, 'Asignacion', "Asignado a {$personal->NombreCompleto}", usuarioId: $usuarioId);
               return $activo->fresh(['estadoCatalogo', 'asignacionActiva.personal']);
           });
       }

       public function devolver(Activo $activo, array $datos, int $usuarioId): Activo
       {
           $asignacion = $activo->asignacionActiva()->with('personal')->first();
           if (! $asignacion) {
               throw new RuntimeException('No hay asignación activa para este activo.');
           }

           return DB::transaction(function () use ($activo, $asignacion, $datos, $usuarioId) {
               $asignacion->update([
                   'Fecha_devolucion' => $datos['Fecha_devolucion'],
                   'Observaciones'    => trim(($asignacion->Observaciones ? $asignacion->Observaciones.' | ' : '').($datos['Observaciones'] ?? '')),
                   'Estado'           => 'Cerrada',
               ]);

               $estadoDisponible = EstadoActivo::where('Grupo', 'Disponible')->first();
               if ($estadoDisponible) {
                   $activo->update(['Estado' => $estadoDisponible->Grupo, 'fk_estado' => $estadoDisponible->id]);
               }

               $this->auditar($activo->id, 'Devolucion', "Devuelto por {$asignacion->personal?->NombreCompleto}", usuarioId: $usuarioId);
               return $activo->fresh(['estadoCatalogo', 'asignacionActiva.personal']);
           });
       }

       public function historialAsignaciones(Activo $activo)
       {
           return $activo->asignaciones()->with('personal')->orderByDesc('Fecha_asignacion')->get();
       }

       private function auditar(int $activoId, string $tipo, string $descripcion,
                                ?string $anterior = null, ?string $nuevo = null, ?int $usuarioId = null): void
       {
           HistorialEvento::create([
               'fk_activo'      => $activoId,
               'Tipo_evento'    => $tipo,
               'Descripcion'    => $descripcion,
               'Valor_anterior' => $anterior,
               'Valor_nuevo'    => $nuevo,
               'fk_usuario'     => $usuarioId,
               'Fecha'          => now(),
           ]);
       }
   }
   ```

2. **Crear `app/Services/PersonalService.php`** (mismo patrón): `listar()`, `crear()`, `actualizar()`, `eliminar()` como baja lógica (`Estado = 'Inactivo'`), con contador de equipos asignados activos.

3. **Logs:** usar `Illuminate\Support\Facades\Log` en los puntos críticos (`Log::info('Activo {etiqueta} creado', [...])`), nunca datos sensibles.

**Criterios de Aceptación:**

- ✅ Transacciones DB en operaciones multi-tabla (asignación + estado + auditoría)

## 📝 Notas Importantes para el Agente de IA

1. **Seguridad:**
   - Nunca hardcodear contraseñas en producción; secretos solo en `.env` (no commitear).
   - Toda escritura protegida por rol (`middleware('role:...')`); toda operación auditable registra usuario y fecha.
   - Validar y sanear entradas en el borde (Form Requests); escapado automático de Blade contra XSS; Eloquent parametriza contra SQLi.
   - Descargas de evidencias siempre autenticadas (no servir `storage/app/public` directamente sin `auth`).

2. **Rendimiento:**
   - Eager loading con `with()` para evitar N+1; nunca `get()` de tablas completas sin límite en datos grandes.
   - Paginación server-side en listas (`paginate()` + `withQueryString()`).
   - Índices en PostgreSQL replicados en las migraciones para campos de búsqueda frecuente.
   - Compilar assets una vez (`npm run build`); en desarrollo `npm run dev`.

3. **Mantenibilidad:**
   - Reglas de negocio en `app/Services`, no en controladores ni vistas. El controlador solo: validar (Form Request), orquestar, devolver vista/redirect.
   - Repetir un patrón existente del codebase vale más que introducir una librería nueva sin necesidad; sin dependencias nuevas salvo aprobación.
   - Formato de código con Pint (`vendor/bin/pint` o `composer exec pint`), ya incluido en `require-dev`.

4. **Pruebas:**
   - Tests feature con `RefreshDatabase` contra BD de pruebas (`Zaico_test`); cubrir camino feliz y un caso de error por proceso.
   - Probar flujos completos de autenticación y autorización (403).

5. **Despliegue:**
   - Docker para consistencia entre ambientes; variables de entorno por ambiente.
   - Backups automáticos de PostgreSQL; `php artisan config:cache route:cache view:cache` en producción.
